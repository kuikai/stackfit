# StackFit Themes

Four locked visual themes for the StackFit fitness app.

## Themes
- **bold-sports/** — High-energy neon pink sports anime, power auras, dynamic poses
- **chibi/** — Super cute oversized-head style, pastel, playful
- **cyberpunk/** — Neon cyan/magenta futuristic sportswear, night city gym
- **dumbbell/** — Bright warm gym style inspired by *How Heavy Are the Dumbbells You Lift?* (Doga Kobo). Includes mega-buff mascot + cute female companion

Each folder contains the key character / mascot assets for that theme.
