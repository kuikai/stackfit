# Dumbbell Theme

Bright warm gym style inspired by *How Heavy Are the Dumbbells You Lift?* (Dumbbell Nan Kilo Moteru? / Doga Kobo).

## Vibe
Warm pinks, oranges, yellows. Clean cel-shading, large expressive eyes, bright motivational gym. Mega-buff trainer mascot with comedic muscle energy + cute athletic companion.
