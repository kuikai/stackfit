# Dumbbell Theme

Bright warm gym style inspired by *How Heavy Are the Dumbbells You Lift?* (Dumbbell Nan Kilo Moteru? / Doga Kobo).

## Assets
- `background.jpg` — Empty warm gym with golden light, behind every dark screen except Home
- `girl-standing.jpg` — Full Home picture (locked companion in the gym)
- `girl-companion-locked.jpg` — Same hero scene; see `COMPANION_LOCKED.md`
- `icons/banner-home.jpg` — Settings card preview
- `icons/icon-companion.jpg` — Portrait used on the Settings card
- `mascots/mascot-companion.png` — Cut-out mascot on Home
- `mascots/mascot-companion-sit.png` — Sitting on the Done / Next Set button
- `mascots/mascot-companion-rest.png` — Lying on the Skip rest bar
- `mascots/animation/running/mascot-companion-run-1.png` through `run-8.png` — Run cycle on workout complete
- `mascot-flex.jpg` / `mascot-dumbbell.jpg` — Mega-buff trainer reference art

## Vibe
Warm pinks, oranges, yellows. Clean cel-shading, large expressive eyes, bright motivational gym. Mega-buff trainer mascot with comedic muscle energy + cute athletic companion.
